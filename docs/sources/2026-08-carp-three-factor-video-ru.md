# Source — Russian carp-fishing video, transcript (owner-supplied)

Supplied by the project owner on 2026-08-18 as 15 iPhone screenshots of the
YouTube transcript panel, read out of Google Drive. Video ID `v6INlcG5jOw`,
runtime ~6:00, language Russian. The video itself could not be fetched — the
build sandbox blocks `youtube.com` — so this file is the record.

**Why it is kept verbatim.** The owner named this the *backbone* of the zone
formula. `CLAUDE.md` law 1 forbids fishing knowledge in code and ADR 0002
requires provenance on every angling coefficient, so the claims have to be
traceable to something a human can re-read and disagree with. Paraphrase in an
ADR is not that.

**One gap:** the frame covering **0:44–1:06** would not OCR (three attempts,
empty each time). It bridges the end of episode 2 and the start of episode 3;
0:44 ends "…по погоде можно определить, где рыбе" and 1:06 resumes mid-list
with the three factors, so the missing seconds appear to be the setup for that
list. Nothing downstream depends on it. Re-upload that screenshot if you want

## What the video does NOT supply

- **The pressure-norm formula.** At 1:36 it says every water body has its own
  norm and that "there is a simple formula to calculate it" — and then never
  states it. That is the paid upsell in episode 9. It must not be guessed at;
  see ADR 0003 for how the norm is obtained instead.
- **Any number for roach, bream, rudd or ide** — the four primary species here.
  The only temperature figures given are for carp (implicitly) and grass carp
  (25–30 °C optimal feeding).
- **Any validation.** One session, 17 fish, no control, no blank sessions
  counted. It is a coherent mechanism, not evidence.
